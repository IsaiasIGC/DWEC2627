Ejercicio 4 - Lista de definiciones

URL
URL (Uniform Resource Locator) es la dirección que permite localizar un recurso en Internet, como una página web, una imagen o un documento.
HTTP
HTTP (HyperText Transfer Protocol) es un protocolo de comunicación que permite el intercambio de información entre un cliente, normalmente un navegador web, y un servidor.
TCP/IP
TCP/IP (Transmission Control Protocol / Internet Protocol) es un conjunto de protocolos de comunicación que permite enviar y recibir datos a través de Internet.
Internet
Internet es una red mundial de redes interconectadas que permite la comunicación y el intercambio de información entre dispositivos.
W3C
W3C (World Wide Web Consortium) es una organización internacional que desarrolla y establece estándares para garantizar el correcto funcionamiento y evolución de la Web.
HTML
HTML (HyperText Markup Language) es un lenguaje de marcado utilizado para estructurar y definir el contenido de las páginas web.
