PT 3.1 – Arrays: parte 1

Ejercicio 1: Array de colores

Crea un array llamado colores usando const y añade tres colores: "rojo", "verde", "azul".

Luego, intenta modificar un color específico del array. Imprime el array completo antes y después del cambio.

Abre la consola del navegador con F12 para consultar los resultados.
