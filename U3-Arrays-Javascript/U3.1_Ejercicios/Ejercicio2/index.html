PT 3.1 – Arrays: parte 1

Ejercicio 2: Array de países

Crea un array llamado "países" que contenga: "España", "Francia", "Alemania", "Italia".

Recorre el array e imprime el nombre de cada país. Después, elimina el primer país del array y vuelve a recorrerlo e imprime el array de nuevo.

Abre la consola del navegador con F12 para consultar los resultados.
