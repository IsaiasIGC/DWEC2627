Ejercicio 3: Gestión de datos con Map

Crea un Map que almacene nombres como claves y edades como valores.

Luego, agrega algunos nombres y edades, actualiza la edad de uno de ellos y, finalmente, imprime todos los nombres con sus edades.

Abre la consola del navegador con F12 para consultar los resultados.
